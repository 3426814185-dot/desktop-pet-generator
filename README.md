# 桌宠生成器 🐾


！！!!!!!!!!!!!!!!!!!!!！！！！!!!!!!!!!!!！！千万不要没有配置api就让他做动作，聊天，会崩溃！！！！！！！！！!!!!!!!!!！！！！！！


上传一张图片 → （可选）AI 识别形象 → 本地抠图 → 生成一只悬浮在桌面上的透明桌宠，会自己走动、跟你聊天、做动作。

纯本地抠图，不依赖 AI 也能生成桌宠。PyQt5 编写，Windows 免安装运行。

## ✨ 功能特性

- **图片生成桌宠**：上传任意含角色的图片（人、猫、卡通角色均可），rembg 本地抠图，自动裁剪到主体边界
- **AI 形象识别**（可选）：视觉模型自动识别名字/种类/性格/外观；不支持识图也能手动填写人设
- **桌宠交互**：
  - 左键拖拽移动，自动走动、上下晃动、呼吸
  - 点击互动，按性格差异化反应（活泼跳、傲娇转身、胆小躲闪…）
  - 右键菜单：聊天 / 走路 / 挥手 / 跳舞 / 跳跃 / 🎬 做动作 / 编辑骨骼 / 关闭桌宠
  - 打招呼气泡（不透明白底，壁纸任意颜色都清晰）
- **性格化行为**：从人设文本自动解析性格（活泼/慵懒/傲娇/黏人/胆小/乐观），决定动作频率与互动反应
- **聊天**：以识别出的角色身份回复，支持流式输出；输入动作短词可直接触发动作
- **骨骼动画**（本地零 API）：框选头/躯干/四肢，走路/挥手/跳舞/跳跃纯本地播放
- **AI 动作生成**（需图像生成 API）：描述一个动作，逐帧生成 + 抠图 + 播放动画
- **像素风**：普通像素化 + 8bit 复古（颜色量化 ≤32 色），像素大小可调、实时预览
- **历史桌宠**：自动保存，可随时重新启动、删除
- **自定义打招呼语**：单独编辑器，可增删，附带系统默认语

## 🚀 快速开始

### 直接运行（推荐）

下载 Release 中的 `desktop-pet-windows-x64.zip`，解压后双击 `桌宠生成器.exe` 即可（免安装，首次抠图会自动下载约 170MB 模型）。

### 从源码运行

```bash
git clone https://github.com/3426814185-dot/-.git 桌宠生成器
cd 桌宠生成器
pip install -r requirements.txt
python run.py
```

> 要求 Python 3.10+（开发环境为 3.11）。

## 📖 使用步骤

1. **选择图片**：选一张含角色的图片
2. **角色设定**（二选一）：
   - ✅ **AI 自动识别**：需支持图片输入的视觉模型，自动识别名字/种类/性格/外观
   - ⬜ **手动设定**：纯文本模型或不用 AI 时，取消勾选后手动填写
3. **AI 配置**：Base URL + API Key + 聊天模型。填 Base URL 后会自动识别服务商并推荐模型（也可从下拉框选择或手动输入）
4. 点击 **生成桌宠**，等待抠图
5. 桌宠出现后，右键它即可聊天、做动作、编辑骨骼

> 💡 核心思路：**抠图完全本地完成，不依赖 AI**。即使没有识图能力，手动填好人设照样生成桌宠；聊天用普通文本模型即可。

## 🕹️ 桌宠玩法

| 操作 | 效果 |
|------|------|
| 左键拖拽 | 移动桌宠到任意位置 |
| 单击 | 按性格差异化反应 |
| 右键 | 打开菜单（聊天/动作/骨骼/关闭） |
| 自动 | 隔几秒随机走动，空闲时呼吸/晃动 |
| 聊天输入动作词 | 如「挥手」「跳舞」，直接触发动作 |

## 📋 支持的 AI 服务商

填 Base URL 后自动识别：OpenAI、DeepSeek、通义千问、智谱 GLM、Kimi、豆包、硅基流动、Claude、Gemini。模型下拉框预置各服务商最新模型，也可手动输入。

- **聊天**：普通文本模型即可
- **AI 识别形象**：需视觉模型（如 gpt-4o、qwen-vl 系列）
- **AI 生成动作**：需支持图像生成接口（OpenAI 兼容 `/images/generations`）

## ❓ 常见问题

- **识别报错**：确认模型支持图片输入、API Key 有效、Base URL 正确。
- **动作生成失败**：AI 动作需服务商支持图像生成接口；无 API 时用右键「走路/挥手/跳舞」体验本地骨骼动画。
- **首次生成慢**：抠图模型（u2net.onnx）首次联网下载，之后缓存到 `~/.u2net/`。
- **配置/历史数据**：存于 `~/.desktop-pet/`（config.json、history.json、骨骼配置、头像缓存）。
